Welcome to the AI Storytelling Project

This project compares human-written and AI-generated stories based on animal shelter data during and after the COVID-19 period.

Compare Stories

Dataset

Austin Animal Center Outcomes

The dataset contains information about animal adoptions, transfers, returns, and other shelter outcomes over several years.

Our project focuses on comparing pet adoption during COVID-19 with abandonment trends in the following years.

Project Objective

The objective of this project is to investigate whether AI-generated stories can achieve similar levels of readability, trustworthiness, and emotional engagement as stories written by humans.
